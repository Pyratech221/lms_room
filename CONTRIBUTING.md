# Contributing

Thanks for contributing to LMCrooms.

## Development workflow

1. Create a branch from `main` (or `master` if that is your default branch).
2. Make small, focused changes.
3. Run the relevant checks locally before opening a PR.
4. Open a pull request with a clear title and summary.

## Coding guidelines

- Prefer readable, maintainable code.
- Keep commits focused and descriptive.
- Follow the existing code style for the relevant stack.

## Commit message suggestions

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
